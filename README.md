# 多无人机跨江配送路径优化

基于 Solomon 数据构建带桥梁通道的跨江配送场景，以配送时间惩罚、闭合总航程和累计飞行风险为三个最小化目标。求解器包括独立实现的 NSGA-II、ALNS-NSGA-II，以及 pymoo 提供的 MOEA/D、SPEA2。

## 安装和检查

需要 Python 3.10 及以上版本。在本目录执行：

```bash
python -m pip install -r requirements.txt
python -m pytest -o addopts='' -q
python scripts/fetch_solomon.py --verify
python scripts/run_preprocess.py --quiet
```

原始数据已随项目提供，离线也可预处理和求解。只有需要重新获取数据时才运行不带 `--verify` 的下载命令。

## 运行实验

四种算法在三个 25 客户场景上分别使用种子 1 至 30，种群为 60，繁殖 150 代：

```bash
python experiments/run_study.py --seeds 30 --workers 12 --out results/study_full
```

消融实验分别关闭 ALNS、贪心初始化和参数调度；续航敏感性分析使用最大航程的 80%、90%、100%、110%、120%。补充实验每种设置使用 10 个种子：

```bash
python experiments/run_study.py --algorithms ALNS_NSGA2 NO_ALNS NO_GREEDY NO_SCHEDULE --seeds 10 --sensitivity --workers 8 --out results/ablation_sensitivity
```

较小的检查运行可使用：

```bash
python experiments/run_study.py --instances R101 --customers 10 --pop 10 --gen 2 --seeds 1 --workers 1 --out results/check
```

每次运行即时保存 JSON，可中断后按同样参数继续。程序检查参数、输入文件与源码哈希，拒绝将不同版本的运行混入已有目录。`--workers` 也在清单中记录，重跑已有目录时须与原记录一致；换参数请改用新的输出目录。Windows 多进程入口已加保护。

## 模型约定

- 算例保留原始坐标、需求、时间窗和服务时间，不把归一化坐标与原时间单位混用。坐标和载重均为算例单位，未经实测标定不能称为米或千克。
- 河流采用水平带状禁飞区。同岸航段为直线，异岸航段经某座桥的近岸端和远岸端，选择最短通道；没有桥时两岸不连通。客户及起降点位于水域内部时拒绝载入。
- 每架同型无人机从同一车场同时出发，执行一条闭合航次。载重、无人机总量、含返航的最大航程及含等待和服务的最大任务时长均为硬约束。暂不建模换电、多趟飞行、异构机队或多起降点。
- 时间窗按论文采用软惩罚。到达客户时计算提前或迟到量，提前到达后等待至时间窗开启才服务。时间目标为各客户到达时刻之和加提前、普通迟到及紧急客户迟到惩罚，权重分别为 1、2、5。
- 风险由障碍物附近的静态指数衰减项和桥梁附近的非负周期项组成，采用固定理论上界归一化。每个真实折线航段按飞行时刻进行中点积分，计入返航；桥梁为合法通道，不把禁飞标记数值累加进风险。
- 河流、桥位、风险参数和紧急客户为人工构造的实验场景，见 `configs/`。这些参数不代表真实长江测绘或事故概率。

解码器将客户排列切分为请求的路径数，在满足硬约束的分段中最小化总航程；请求路径数不可行时取最近可行值。该解码器带有距离偏好，三目标搜索得到的是启发式近似前沿，不保证覆盖所有可行分段。相同解码器用于全部对照算法。距离与车辆数是否存在冲突取决于实例和约束，不能据三角不等式推导为全局单调关系。

## ALNS 实现

2026-10-31 已修复预算参数校验和重复运行时的初始概率恢复，详见 [ALNS 检查记录](docs/alns_review_20261031.md)。

初始种群包含 20% 最近邻排列、20% 最早截止时间排列和其余随机排列。交叉率按代数从 0.9 线性递减至 0.5，变异率从 0.1 递减至 0.05。

每代只增强最多 5 个不同目标向量的非支配精英。破坏算子为随机移除及按实际路径边际航程贡献移除，修复算子为贪婪可行插入和随机可行插入。移除比例为 5% 至 10%，小规模实例向上取整到至少一个客户。插入时检查载重、任务时长和返航航程，最终重新解码并评价完整方案。

局部搜索最多 15 轮，连续 5 轮没有标量改善即停止。模拟退火初温 0.5，降温系数 0.95；接受判断先按该代可行种群尺度归一化目标。算子通过轮盘赌选择，按支配改善、标量改善、接受非改善解分别计 10、5、1 分，拒绝和修复失败计 0 分，并使用反应系数 0.1 更新权重。已有精英与所有局部候选共同参加环境选择，退火接受劣解不会直接覆盖原精英。

## 结果文件

| 文件 | 内容 |
|---|---|
| `results/study_full/manifest.json` | 参数、依赖版本、源码及输入 SHA-256 |
| `runs/*.json` | 每个算法和种子的前沿、路径、收敛过程、求解时间、评价次数 |
| `metrics.csv` | 每次运行的 HV、IGD、Spacing、时间和前沿规模 |
| `summary.csv` | 各算法指标均值及 HV 标准差 |
| `significance.csv` | 同种子配对 Wilcoxon 检验及同算例 Holm 校正 |
| `*_reference.json` | 经验参考前沿、共同归一化尺度及 HV 参考点 |
| `*_selected.json` | 从改进算法全部种子非支配并集中等权模糊选出的方案 |
| `*_risk_maps.npz` | 两个时刻的风险网格，禁飞水域为 NaN |
| `study.sqlite3` | 完整运行记录，主键去重 |
| `figures/` | 三目标前沿、收敛、统计、真实绕桥路径和动态风险快照 |
| `results/ablation_sensitivity/` | 消融及续航扰动结果 |

最终指标在每个算例内使用同一批所有算法、所有种子的共同尺度。HV 的归一化参考点为 (1.1, 1.1, 1.1)；IGD 参考集为本批运行的非支配并集，并非已知真实最优前沿。收敛曲线采用包含各代点的另一组共同尺度，详见 `*_convergence_scale.json`，其数值不能直接与最终指标表混比。

同代数下 ALNS 会增加评价次数，因此实验属于相同种群和代数的比较。评价预算及墙钟时间均已记录，不据此声称严格等算力优越。并行运行的墙钟时间受系统负载影响，不是独占处理器的 CPU 用时。统计检验报告双侧结果，是否改善还须看均值差方向；小前沿的 Spacing 较小不代表一定更优。

## 数据精度

上游 `.sol` 的声明成本使用每条边向下截断到一位小数的距离。全部 56 个参考解的声明成本及路径可行性均可在该约定下复核。原 10 客户 VRPTW 基线继续使用精确欧氏距离，不能把两种精度的差异解释成上游数据缺陷，也不能直接拿不同口径的数值计算改进率。详见 [数据说明](docs/data_notes.md)。

旧的 10 客户双目标结果保留在 `results/` 原子目录，复现入口为 `experiments/run_baseline_n10.py`。它们属于不含河流和风险的 VRPTW 对照，不与三目标场景直接比较。
